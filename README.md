[One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).
`main.py` writes a single deadpan one-star review of gravity to
`/output/entry.txt`: a genuine complaint filed in earnest against a thing
that cannot be fixed — no off switch, drops everything you own — with
the sting arriving in the last few words, "Would not recommend."
Python standard library only, deterministic, 117 characters, one line.
